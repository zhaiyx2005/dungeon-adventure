# 地牢冒险记

一款卡牌构筑 + 地牢推进 + 队伍养成的单人 PVE 游戏。

- **引擎**：Godot 4.3（2D，GL Compatibility）
- **题材**：西幻地下城。冒险镇旁突然出现怪物地下城，你从农夫之子起步，目标是成为勇者。
- **玩法参考**：战斗与地图取自《杀戮尖塔》，队伍与装备取自《暗黑地牢》
- **当前阶段**：框架 / 数值 / 数据已定稿，核心代码骨架已写，**战斗玩法待实现**

---

## 快速开始

```bash
# 1. 用 Godot 4.3 打开本文件夹（可直接导入）

# 2. 重新生成游戏数据（改完数据表后执行）
python tools/generate_data.py
```

数据改动的正确流程：

```
改 tools/generate_data.py 里的数据表  →  跑脚本  →  data/ 全量重新生成
```

**不要手改 `data/` 下的 `.tres`**，会被脚本覆盖。

## 已定稿的核心规则

**战斗回合**
- 小队共享一个回合，任意出牌，手动点「结束回合」
- 行动值每人各自持有，回合开始回满（不累积）
- 蓝量：法术卡消耗，每回合 +5

**伤害**
```
最终伤害 = max(攻值 × 卡牌倍率 − 对应抗性, 1)     暴击 ×1.5
```

**战力**（人物与怪物共用同一公式）
```
血量×0.5 + (物攻+法攻)×1.5 + (物抗+法抗)×1.0 + 技巧×2.0
```

**濒死**
- 血量归零 → 濒死，不能出牌，但仍在场
- 需「复活术」救回，救回后血量为 1
- 全队濒死 → 任务失败，失去背包物品与本次金钱经验，**保留卡组牌与已穿装备**

**地牢**
- 每层 3 列 × 7 行，随机连线，节点内容随机（战斗/宝箱/事件 = 70/10/20）
- 打完 Boss 可选返回城镇或继续向下
- 队伍总战力必须 ≥ 该层推荐战力下限才可进入，缺口靠装备补

**怪物 AI**
- 每回合最多 3 只怪物攻击同一个人物
