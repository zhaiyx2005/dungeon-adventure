**所有生成物都不要手改**——改源头再重新生成。



### 音频（`.wav`）

```bash
PY tools/generate_audio.py         # 纯 Python 合成 14 音效 + 2 BGM，无需任何依赖
"$GODOT" --headless --path . --import
PY tools/patch_audio_import.py     # 改导入参数：PCM + BGM 前向循环
"$GODOT" --headless --path . --import
```

> 🔴 音频导入有两个静默坑：默认压缩是有损的 QOA；`.import` 里的 `edit/loop_mode`

## 玩法规则（当前代码的实现）

> 想确认某条规则，以 `docs/数值设计_v1.0.md` + 代码为准；
> `数值设计_v2.0.md` 是**下一版设计**，尚未落地。

### 战斗

- 小队共享一个回合，任意出牌，手动点「结束回合」
- **每回合开始**：每个角色恢复 **1 点行动点、5 点蓝量**（各自不超过上限；上限由属性决定）
- 打出一张卡消耗它的行动点与蓝量；行动点用光就只能结束回合
- 出牌方式：把卡从手牌**拖到目标身上**；只能对自己用的卡直接指向释放者
- 护盾**先扣、回合结束时清空**
- 使用道具消耗 **1 点行动点**
- 敌方**每回合最多 3 只怪攻击同一个人**

### 卡牌

- 六分类：进攻 / 防御 / 特殊 × 物理 / 法术。**物理卡不耗蓝，法术卡耗蓝**
- 手牌上限 **12**；进入新节点时重新抽 **8** 张起手；之后每回合抽 **2**；牌库抽空把弃牌堆洗回
- 卡面写着倍率（如「物攻 ×1.8」），倍率越高越吃对应属性

### 联合卡（共鸣）

组件卡（风之符文、火之符文…）单独打出**没有任何效果**，只在本回合内「就位」。
**同一回合内把一组组件全部打出**，对应的联合卡本体才按得下去 ——
前置没凑齐时手牌里的联合卡会变暗、拖不动。部件槽以我方回合为界，回合结束清空。

### 地牢

- **5 层**：新手地穴 · 幽暗回廊 · 深渊裂口 · 巫王墓庭 · 深渊之底
- 每层是一张分叉小地图（3 列），节点内容随机（战斗 70% / 宝箱 10% / 事件 20%），终点是层 Boss 房
- 打赢层 Boss 后可选**撤离**（带走战利品，结束本轮）或**继续向下**
- 通关过某层 Boss 后，下次出征可**付金币直接从那一层开始**（0 / 100 / 400 / 900 / 1600，第 1 层免费）

### 失败与代价

- 血量归零 → **濒死**，不能出牌但仍在场；需「复活术」救回，救回后血量为 1
- 全队濒死 → 本轮失败：金币 / 经验 / 等级 **回滚到本轮开始之前**，背包里的随身物品清空
- **仓库**里的东西不受影响 —— 贵重物品记得先存进仓库

### 人物养成

四属性：**体质**（血量 + 双抗）· **力量**（物攻）· **智力**（法攻与治疗）· **精力**（行动点）

```
血量 = 体质×6 + 精力×2 + 力量×1          蓝量 = 智力×4 + 精力×2 + 体质×1
物攻 = 力量×2 + 精力×0.5                法攻 = 智力×2 + 精力×0.5
物抗 = 体质×1 + 力量×0.5                法抗 = 体质×1 + 智力×0.5
技巧 = (智力 + 力量) × 0.5
```

**战力**（人物与怪物**共用同一公式**）
```
血量×0.5 + (物攻+法攻)×1.5 + (物抗+法抗)×1.0 + 技巧×2.0
队伍总战力 = 成员战力合计 × 人数系数（1 人 1.00 / 2 人 1.05 / 3 人 1.10 / 4 人以上 1.15）
```

**伤害**
```
最终伤害 = max(攻值 × 卡牌倍率 − 对应抗性, 1)      暴击 ×1.5
```

升级获得属性点，去「作战整备」分配。

### 存档

- **10 个栏位**（`user://save_00.json` … `save_09.json`）
- 点「存档」→ 点空栏位写入；点已有存档**先确认再覆盖**
- 点「读档」→ 点已有存档载入（空栏位置灰）
- 每档记录**累计游玩时长**与**最后保存时间**；时长跟着档走，换栏位不会混
- v1 时代的单文件 `save.json` 首次运行会自动迁移进栏位 1

## 开发时最容易踩的坑（每条都真实踩过）

| 坑 | 一句话 |
|---|---|
| 🔴 导出版「卡牌全不见」 | 导出会把 `.tres` 改写成 `.tres.remap`，`ends_with(".tres")` 扫到 0 个且**不报错**。统一走 `GameDatabase.list_data_files()` |
| 🔴 `--check-only --script` 报 autoload 找不到 | **假阳性**：该模式不注册 autoload。场景脚本必须靠真实运行验证 |
| 🔴 `--headless` 通过 ≠ 贴图没问题 | headless 用 dummy 渲染器，**贴图解码路径与真渲染不同**，导出后必须再跑一次真渲染 |
| 🔴 含 `await` 的测试函数必须 `await` | 不 await 只是挂起协程，断言打印在汇总之后 —— 数字看着对其实没计入 |
| 🔴 `class_name` 脚本里不能写 autoload 标识符 | 用 `root.get_node_or_null(...)`；场景脚本不受限 |
| 🔴 素材 `.import` 不能从旧素材复制 | 会撞 uid；删掉新素材的 `.import` 重跑 `--import` |
| `.import` 参数枚举 ≠ 运行时枚举 | `edit/loop_mode` 要写 `2` 才是前向循环（写 1 会静默变「自动检测」→ BGM 放一遍就停） |
| `Control` 没有 `to_local()` | 全屏覆盖层换算用 `get_global_transform().affine_inverse() * point` |
| 同一 canvas 内 `z_index` 是全局排序 | 截图遮罩只靠「后 `add_child`」盖不住特效层 |
| `unique_name_in_owner` 漏配 = 静默功能缺失 | `%Foo` 拿到 null，只 push 一个 ERROR |

更多细节见 `docs/` 下各文档，以及 `HANDOFF.md`。
