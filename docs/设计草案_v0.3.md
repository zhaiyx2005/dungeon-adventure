## 一、定位

- 类型：卡牌构筑 + 地牢推进 + 队伍养成的单人 PVE 游戏
- 参考坐标：战斗与地图取自《杀戮尖塔》，队伍与装备取自《暗黑地牢》
- 引擎：Godot 4
- 美术：首版用纯色框 + 文字占位
- 首版范围：**只做 PVE，不做 PVP**
- 当前阶段：**框架设计**（数字与公式另行定档）

## 二、流程总览

```
主菜单
  ├─ 冒险者工会（接任务 / 招募 / 组队 / 提升成员）
  ├─ 作战整备（队伍 / 卡组 / 背包 / 仓库）
  ├─ 商店（买卖）
  ├─ 仓库
  ├─ 卡牌大全
  ├─ 地下城探索 ──→ 组队出发 ──→ 逐层推进 ──→ 撤离回城 / 任务失败
  ├─ 游戏设置
  └─ 退出游戏
```

主界面右上角常驻显示**金币数量**。

**核心循环**：

> 工会备整（接任务、招募、组队、加点）→ 地牢推进（选路、战斗、开箱、事件）→ 撤离带回战利品 / 或全队濒死失败 → 回城养成 → 挑战更深层级

## 三、地下城框架

### 3.1 层级与推进

- 地下城按**层**组织，每层为一张 **3 列 × 7 行** 的路线图
- 玩家从**最下方**进入，向**层 Boss** 推进（自上而下 or 自下而上由实现决定，逻辑一致）
- 每层终点为**层 Boss 房**，击败后**必出宝箱**
- 打完 Boss 由玩家选择：**返回城镇**（本轮结束，带走战利品）或 **继续向下**（进入更深一层）
- 层数越深，**危险等级**越高 → 更强怪物与事件，更丰厚奖励

### 3.2 地图生成规则

- 网格 3 列 × 7 行 = **21 个节点**
- 相邻行的节点之间**随机连接**（形成多条路线）
- 每个节点的内容随机分配：**战斗 / 宝箱 / 事件**（比重待定）
- 玩家在每行选择一个可达节点前进

### 3.3 层级准入

- 可**提交金币直接进入指定高层级**
- 进入前显示「推荐总战力」与「我方队伍总战力」，由玩家对比决策

## 四、战斗框架

### 四、战斗框架

#### 4.1 回合模型

- **小队整体共享一个回合**
- **回合的起止定义**：从「我方回合开始」到「下一个我方回合开始前」视为**一个回合**
  - 即：我方回合 → 敌方回合 → 回到我方回合开始 = 1 回合
- 回合内**可任意次数出牌**，唯一约束是各角色的**行动值**
- 玩家主动点击**「结束回合」**才结束，无强制上限（不会自动跳过）

#### 4.1.1 抽牌规则

| 时机 | 抽牌 |
|---|---|
| **进入新的战斗节点** | 一次性抽 **8 张** |
| **之后每个回合开始** | 基础抽 **2 张** |
| 牌库抽空 | **立即将弃牌堆洗牌**放回抽牌堆（可继续抽） |

- 回合开始时**同时恢复所有角色的行动值**（**回满**，不跨回合累积）
- 回合开始时**手牌保留**
- 每个节点开始时手牌**清空重抽**
- 首版基础抽牌为每回合 2 张（不随等级/装备提升）

### 4.2 资源消耗规则

| 资源 | 归属 | 消耗来源 |
|---|---|---|
| **行动值** | 每个角色各自持有 | 攻击卡、防御卡、特殊卡、**背包道具** |
| **蓝量** | 每个角色各自持有 | **法术类卡牌** |
| 血量 | 每个角色各自持有 | 受击 |
| 行动值 | — | **每回合开始时恢复**（恢复量待定 N5） |
| 蓝量 | — | 恢复规则待定（N6） |

> 要点：道具也吃行动值——这是玩家在「出牌」与「用道具」之间的取舍点。

### 4.3 界面布局（参考《杀戮尖塔》）

- **正下方**：手牌区，扇形分布
- **左下角**：背包（点开使用消耗品道具卡牌）
- **右侧**：抽牌堆、弃牌堆
- **中间左侧**：小队人物卡牌，依次排列
- **中间右侧**：怪物卡牌，依次排列
- 中间以**剑与盾**分隔两军

### 4.4 操作流程

1. 点击人物卡牌 → 选择由谁释放
2. 拖动卡牌释放
   - **单体卡**：拖到目标卡牌上使用
   - **全场效果卡**：拖到战斗场上直接使用

### 4.5 伤害与暴击

```
基础伤害 = 攻击方对应攻值 × 卡牌倍率
最终伤害 = 基础伤害 − 受击方对应抗性      （最低保底待定）
暴击时   = 最终伤害 × 1.5
```

- 攻击与暴击判定**对人物和怪物同样生效**
- **暴击值越高 → 暴击概率越高**
- 暴击伤害倍率 = **×1.5**

**卡牌倍率示例**：
- 普通物理攻击 = 1 倍物攻
- 雷击术 = 1.2 倍法攻

### 4.5.1 防御卡机制（护盾）

- 防御卡为使用者提供**护盾值**
- 结算顺序：**先扣护盾，护盾耗尽后再扣血量**
- 护盾持续时间：**到本回合结束**（即到下一个我方回合开始前失效）
- **含义已确认**：护盾覆盖「我方出牌 → 敌方行动 → 回到我方」整段，**能抵挡敌人的攻击**（解释 A）

> 推论：护盾的有效窗口是「我方出牌 → 敌方行动 → 回到我方」这一段，因此防御卡本质是**为敌方行动回合预付的保险**。

### 4.5.2 敌人编成

- 怪物**有成队出现，也有单只出现**，由关卡节点数据决定
- 战斗因此为 **N vs M**（我方最多 4 人 vs 敌方若干）

### 4.6 濒死与失败

- 小队成员**血量归零 → 进入濒死状态**，**无法使用任何卡牌**（不可行动，但未离场）
- 濒死成员**可被救回**：需使用专门的技能卡（如**复活术**），使其**血量恢复为 1**
- 小队**所有成员均濒死 → 判定任务失败**，直接跳回城镇

## 五、死亡惩罚与激励

### 5.1 失败损失（全队濒死）

| 会失去 | 不会失去 |
|---|---|
| 背包内**所有物品卡牌** | 卡组内的战斗卡牌 |
| 本次探索获得的**金钱** | 人物身上**已穿着的装备** |
| 本次探索获得的**经验** | 已拥有的人物卡牌 |

> 关键设计含义：**背包是风险区，穿着是安全区**。玩家在「穿上保命」与「留背包赌更大」之间做取舍。

### 5.2 成长激励

- **击败节点怪物** → 小队成员获得**经验**
- 经验满 → **升级** → 获得 **1 点属性点**（等级高则数值高、战力高）

### 5.3 刷新次数

- 每次**进入地下城**时，以下三处各获得**刷新次数**：
  - 商店
  - 接取任务
  - 招募成员
- 刷新次数**最多积攒 3 次**

## 六、数值框架

### 6.1 人物

**四个基础属性**：体质、力量、智力、精力

**八个派生数值**：

| 数值 | 主 | 次 | 次 |
|---|---|---|---|
| 血量 | 体质 | 精力 | 力量 |
| 蓝量 | 智力 | 精力 | 体质 |
| 行动值 | 精力 | 体质 | — |
| 物攻 | 力量 | 精力 | — |
| 法攻 | 智力 | 精力 | — |
| 物抗 | 体质 | 力量 | — |
| 法抗 | 体质 | 智力 | — |
| 技巧/暴击 | 智力 | 力量 | （同等重要） |

**幸运**：角色初始自带的独立属性；可通过**装备**或**珍贵道具**（如幸运提升药水）提升。

**战力**：由除幸运外的其他数值换算（人物战力函数）。

**成长**：升级 → +1 属性点 → 分配至四基础属性 → 派生数值提升 → 战力提升。

### 6.2 怪物

怪物数值：血量、物攻、法攻、物抗、法抗、技巧/暴击、战力
（无蓝量、无行动值）

**战力**由怪物战力函数换算。

### 6.3 幸运的作用（全局）

**队伍总幸运值**影响：
- 宝箱开启的物品产出
- 怪物的掉落产出

## 七、卡牌体系

### 7.1 顶层分类

| 类型 | 可获取 | 说明 |
|---|---|---|
| 冒险者人物卡牌 | 是 | 含主角，可养成 |
| 怪物卡牌 | 否 | 仅战斗时作为敌人出现 |
| 物品卡牌 | 是 | 装备 / 道具 / 收集品 / 战利品 / 杂物 |
| 战斗卡牌 | 是 | 攻击 / 防御 / 特殊 |

### 7.2 战斗卡牌

- **攻击卡**：普通物理攻击、普通法术攻击等，造成伤害
- **防御卡**：普通物理防御、普通法术防御等，抵挡伤害
- **特殊卡**：治愈术等；给敌方负面效果、给我方正面效果
  - **复活术**：可将濒死成员救回，血量变为 1

**卡组归属**：**全队共用一副卡组**（不区分角色个人牌库）

**卡组容量**：至少 **20 张**，至多 **40 张**

### 7.3 物品卡牌

**装备卡牌**（提升佩戴者数值，另有「珍贵值」→ 显示颜色）

- 防具：头部 / 颈部 / 身体 / 手部 / 腿部 / 脚部
- 武器：单手武器 / 双手武器 / 远程武器

珍贵度颜色：白 / 绿 / 蓝 / 紫 / 金 / 红（区间见数值设计 v1.0 第九节）

**道具卡牌**：回血瓶、回蓝瓶等消耗品。
**收集品卡牌**：胜利王冠、光辉水晶等。获取：宝箱 / 商人 / 怪物掉落。用途：卖给商人换大钱 / 兑换特殊人物卡牌 / 收藏。
**战利品卡牌**：野猪人王獠牙、吸血蝙蝠翅膀等。获取：怪物掉落。用途：消耗以提升人物等级 / 收藏。
**杂物卡牌**：破旧的剑、残破的笔记本等。获取：宝箱 / 怪物掉落。用途：卖商人换小钱 / 收藏。

## 八、城镇系统

### 8.1 冒险者工会

- **接取任务**：如"击败 3 只野猪怪"，奖励金币与物品卡牌；任务有推荐战力，越高奖励越丰厚
- **招募成员**：金币购买冒险者人物卡牌，战力越高越贵；可能刷新**特殊人物卡牌**，需金币 + 特定收集品卡牌兑换
- **组建队伍**：主角 + 已有人物卡牌，最多 **4 人**，产出**小队总战力**
- **提升成员**：加属性点升级；或消耗战利品卡牌直接提升等级

### 8.2 作战整备

- 查看当前小队成员、卡组、背包
- 成员：加点、穿脱装备
- 背包与仓库互相存取
- 卡组：选择带入地下城的卡组

### 8.3 商店 / 仓库 / 卡牌大全

- 商店：购买入背包 / 售卖背包物品
- 仓库：长期存储
- 卡牌大全：按分类查看全部卡牌

## 九、并行开发架构

按「数据 / 逻辑」分层，而非按「卡牌 / 怪物 / 战斗」纵向切。

```
res://data/schema/      单点独占 —— 数据结构定义
res://data/cards/       卡牌任务独占
res://data/monsters/    怪物任务独占
res://data/dungeons/    关卡任务独占
res://scripts/core/     单点独占 —— 战斗引擎
```

**协作原则**：
- 主任务把控全局（规范 + 引擎 + UI），专项任务只产出**数据文件**
- 协作媒介是**文件**，不是对话
- 游戏运行时**读取数据文件**，而非向专项任务索要
- 并行前必须先交付：①字段规范 ②样例数据 ③校验脚本
- 每个并行任务的指令须写明"只改自己目录，不动 `scripts/`"

**推进顺序**：先串行做「规范 + 最小可跑战斗」，骨架稳了再开并行铺内容。
