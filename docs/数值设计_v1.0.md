## 二、属性 → 数值换算

### 2.1 派生公式

设：`T`=体质，`S`=力量，`I`=智力，`V`=精力

```
血量   = T×6 + V×2 + S×1
蓝量   = I×4 + V×2 + T×1
行动值 = V×1 + T×0.2          （取整）
物攻   = S×2 + V×0.5
法攻   = I×2 + V×0.5
物抗   = T×1 + S×0.5
法抗   = T×1 + I×0.5
技巧   = (I×1 + S×1) × 0.5
```

> 设计意图：
> - 主属性系数最大，次属性约为其 1/2 或更小，保证"堆主属性"有明确收益
> - 血量的三属性分配让"肉"有不止一种走法（纯体质 / 体质+精力）
> - 技巧双属性等权，成长慢（每级约 +1），因此暴击率天然偏低，需要装备补

### 2.2 默认人物（1 级，初始属性 5/5/5/5）

| 数值 | 计算 | 结果 |
|---|---|---|
| 血量 | 30+10+5 | **45** |
| 蓝量 | 20+10+5 | **35** |
| 行动值 | 5+1 | **6** |
| 物攻 | 10+2.5 | **12** |
| 法攻 | 10+2.5 | **12** |
| 物抗 | 5+2.5 | **7** |
| 法抗 | 5+2.5 | **7** |
| 技巧 | (5+5)×0.5 | **5** |
| 幸运 | 初始自带 | **3** |

> 派生数值**向下取整**。

## 三、升级与成长

### 3.1 经验曲线

| 等级 | 升到下一级所需经验 | 累计 |
|---|---|---|
| 1 → 2 | 100 | 100 |
| 2 → 3 | 150 | 250 |
| 3 → 4 | 220 | 470 |
| 4 → 5 | 300 | 770 |
| 5 → 6 | 400 | 1170 |
| 6 → 7 | 520 | 1690 |
| 7 → 8 | 660 | 2350 |
| 8 → 9 | 820 | 3170 |
| 9 → 10 | 1000 | 4170 |

**公式**：`所需经验 = 100 + (等级−1) × 60 + (等级−1)² × 10`

- 每级 +1 属性点，**不给**其它自动成长
- 属性点可自由分配，**不可洗点**（首版）

### 3.2 经验来源

| 来源 | 经验 |
|---|---|
| 普通节点战斗胜利 | 60 |
| 精英节点战斗胜利 | 120 |
| 层 Boss 胜利 | 300 |
| 事件节点 | 0–80（随机） |

> 按此设计，一场 run 打 8 个普通节点约 480 经验，能从 1 级升到 4 级左右。

## 四、伤害与暴击

### 4.1 伤害公式（减法式）

```
基础伤害 = 攻击方攻值 × 卡牌倍率
最终伤害 = max( 基础伤害 − 受击方对应抗性 , 1 )
暴击伤害 = 最终伤害 × 1.5        （向下取整）
```

- **保底 1 点**：防止完全破不了防
- 物理卡对物抗、法术卡对法抗，**一一对应**

### 4.2 暴击概率曲线

```
暴击率 = 技巧 / (技巧 + 50 + 目标等级 × 10) × 0.75
```

- 上限 **75%**，下限 **0%**
- 分母含目标等级 → **打高等级敌人暴击率自然下降**

| 技巧 | 对同等级(Lv1) | 对 Lv5 | 对 Lv10 |
|---|---|---|---|
| 5 | 6.8% | 5.0% | 3.8% |
| 10 | 13.0% | 9.5% | 7.1% |
| 20 | 24.0% | 17.6% | 13.2% |
| 40 | 41.1% | 30.0% | 22.5% |
| 80 | 61.5% | 45.0% | 33.8% |

> 要明显提升暴击率，主要靠**装备与道具**（技巧加成），而非纯属性点——这符合"装备驱动"的收集设计。

## 五、战力函数

### 5.1 人物战力（均衡加权）

```
人物战力 = 血量 × 0.5
         + (物攻 + 法攻) × 1.5
         + (物抗 + 法抗) × 1.0
         + 技巧 × 2.0
```

- **幸运不计入战力**（框架规定）
- 保留 1 位小数，显示时向下取整

**示例（默认 1 级人物）**：

```
45×0.5 + (12+12)×1.5 + (7+7)×1.0 + 5×2.0
= 22.5 + 36 + 14 + 10
= 82.5 → 战力 82
```

### 5.2 怪物战力（同结构，不同系数）

```
怪物战力 = 血量 × 0.5
         + (物攻 + 法攻) × 1.5
         + (物抗 + 法抗) × 1.0
         + 技巧 × 2.0
```

> **刻意与人物使用同一套系数**——这样"战力"才能在人物和怪物之间直接比较，平衡时才有一个统一标尺。这是整个数值体系能否运转的关键。

### 5.3 小队总战力

```
小队总战力 = Σ 各成员战力 × 队伍系数
队伍系数：1人 1.0 / 2人 1.05 / 3人 1.10 / 4人 1.15
```

- 队伍系数奖励组队，避免"单人堆一个超人"的最优解

**示例**：

| 队伍 | 成员战力 | 总战力 |
|---|---|---|
| 单人 | 82 | 82 |
| 3 人 | 82 / 82 / 82 | 82×3×1.10 = **271** |
| 4 人 | 82/82/82/82 | 82×4×1.15 = **377** |

## 八、怪物数值模板（按层）

### 8.1 层级基准

| 层级 | 危险等级 | 推荐总战力 | 怪物战力区间 | 单只血量 | 单只物攻 |
|---|---|---|---|---|---|
| 第 1 层 | D | 60–100 | 70–110 | 35–50 | 10–14 |
| 第 2 层 | C | 150–220 | 150–220 | 55–75 | 18–24 |
| 第 3 层 | B | 300–420 | 280–420 | 80–110 | 28–38 |
| 第 4 层 | A | 550–750 | 500–750 | 120–160 | 42–58 |
| 第 5 层+ | S | 900+ | 800+ | 180+ | 65+ |

> 推荐总战力大致按 **每层 ×1.8** 递增。玩家需要"打一层、练一级、再下一层"才能跟上。
>
> **准入规则（已确认）**：队伍总战力**必须 ≥ 该层推荐总战力下限**才允许进入；进入下一层/高层级时，**中间的战力缺口靠装备补**。

### 8.1.1 怪物 AI 集火规则

- **每回合最多 3 只怪物攻击同一个人物**
- 超过 3 只时，多余怪物需**改打其他人**（若无可选目标则本回合待机或打最低血目标）

> 这条规则的作用：在"4 人 vs 4 怪"的场合，避免一个人物被全部火力秒杀，显著降低前期减员速度。

### 8.2 怪物类型模板

**普通（节点常见）**：战力 = 层级基准 × 1.0
- 单只出现，或 2 只组队

**精英（较少见）**：战力 = 层级基准 × 1.6，血量 ×2
- 单独出现，奖励翻倍

**Boss（每层终点）**：战力 = 层级基准 × 3.0，血量 ×5
- 单独出现，必有宝箱

**示例：第 1 层普通怪「野猪怪」**

| 数值 | 值 |
|---|---|
| 血量 | 42 |
| 物攻 | 12 |
| 法攻 | 0 |
| 物抗 | 6 |
| 法抗 | 4 |
| 技巧 | 4 |
| 战力 | 42×0.5 + 12×1.5 + 10×1.0 + 4×2 = **51** |

**示例：第 1 层 Boss「野猪人王」**

| 数值 | 值 |
|---|---|
| 血量 | 220 |
| 物攻 | 26 |
| 法攻 | 10 |
| 物抗 | 14 |
| 法抗 | 10 |
| 技巧 | 8 |
| 战力 | 110 + 54 + 24 + 16 = **204** |

## 十、掉落与幸运

### 10.1 幸运的作用

```
幸运加成 = 队伍总幸运 × 0.02          （每点 +2%）
掉落品质权重的幸运修正 = ×(1 + 幸运加成)
```

- **队伍总幸运** = 所有成员幸运之和
- 影响：宝箱开出的物品品质、怪物的掉率

**示例**：队伍总幸运 12 → +24% 品质权重

### 10.2 节点内容比重

| 内容 | 比重 |
|---|---|
| 战斗 | 70% |
| 宝箱 | 10% |
| 事件 | 20% |

> 对应草案中的"约 1:7:2"（宝箱 : 战斗 : 事件）。

## 十三、平衡检查表

用这套默认值跑第一版战斗时，重点观察：

1. **一名角色一回合出 3 张普通攻击卡**，能否在 4 回合内击杀同层普通怪？
   （12 物攻 ×1.0 − 6 物抗 = 6 伤害 ×3 张 = 18/回合，4 回合 = 72 > 42 血 ✅）
2. **怪物打人物**：12 物攻 − 7 物抗 = 5 伤害。受"每回合最多 3 只集火同一人"限制，一人一回合最多掉 15 血 → 45 血约撑 3 回合
   - 仍在可控范围，**防御卡与治疗卡是必需的**，符合设计意图
3. **战力 82 的人物 vs 战力 51 的怪物**：战力比 1.6，战斗应该偏轻松
4. **层级准入**：队伍总战力**必须达到推荐下限**才可进入。第 2 层下限 150，而 4 级人物约 110 ⚠️
   - 这是**刻意设计**：缺口必须靠**装备**补足。玩家需在城镇阶段穿好装备再下探，强化了"装备收集"的价值

> 第 2 条已通过"集火上限 3 只"缓解；第 4 条是**刻意设计**（装备补强）。先用默认值跑起来，测量真实数据再调。
