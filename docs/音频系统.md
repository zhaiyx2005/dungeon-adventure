# 音频系统（9-25）

> 需求原文：「为攻击，受击，防御，法术添加音效，开屏也要有音乐，点击按钮也要有声音」

## 零、一句话概览

素材全部由 `tools/generate_audio.py` **程序化合成**（纯 Python，无第三方依赖），
运行时由 autoload `AudioManager` 统一调度：

```
tools/generate_audio.py   →  assets/audio/*.wav
tools/patch_audio_import.py →  修正 .import（PCM + 循环）
scripts/core/audio_manager.gd →  总线 / 音效池 / BGM 交叉淡入 / 按钮自动挂音
```

**为什么不用现成素材**：项目当前所有美术都是程序绘制的占位色块（见 `项目状态` 一节的"待办"），
音频走同一条路线 —— 可确定性重跑、不依赖外部素材交付、改参数即改音色。
等真实美术/音频接入时，只要替换 `assets/audio/*.wav` 并保持文件名与 id 不变即可。

### 音乐（2 个，22.05kHz / 16bit PCM / 立体声 / **无缝循环**）

| id | 文件 | 时长 | 内容 |
|---|---|---|---|
| `title` | bgm_title.wav | 24.0s | **开屏 / 主菜单 / 城镇 / 地牢**通用。80 BPM 8 小节，D 小调五声；弦垫 + 拨弦旋律 + 远处太鼓 + 反馈延迟 |
| `battle` | bgm_battle.wav | 20.0s | **战斗**。120 BPM 10 小节，底鼓/军鼓/踩镲 + 八分音符低音 ostinato + 和弦顿奏 + 铜管动机 |

**无缝循环怎么做的**：`Buf.fold_loop()` —— 多渲染 0.35s 尾巴，再把它按线性权重混回开头，
最后裁掉尾巴。这样循环接缝处的跳变实测 ≤ 0.0005（探针里叫 `seam`）。
另外标题曲的整体音量起伏用了周期 24s / 6s 的两个正弦（都是 24 的整数分频），
保证 `env(0) == env(24)`，起伏本身也不会在接缝处断开。

## 二、生成管线（4 步，改音色后必须按序跑）

```bash
PY tools/generate_audio.py            # 1. 合成 16 个 wav
godot --headless --path . --import    # 2. 首次导入 → 生成 .import
PY tools/patch_audio_import.py        # 3. 修正导入参数（见下节两个坑）
godot --headless --path . --import    # 4. 按新参数重新导入
PY tools/_probe_audio.py              # 5. 数值 + 波形复核
```

`PY` = `C:/Users/20601/.workbuddy/binaries/python/envs/default/Scripts/python.exe`

### 🔴 坑 1：WAV 导入默认是有损压缩

Godot 4.7 的 WAV 导入器默认 `compress/mode=2`（Quite OK Audio，有损）。
音乐床与打击音效都不适合，必须改 `compress/mode=0`（PCM）。

### 🔴 坑 2：`.import` 的 `edit/loop_mode` 是**另一套枚举**

```
导入器枚举：0=Disabled  1=Detect From WAV  2=Forward  3=Ping-Pong  4=Backward
运行时枚举：AudioStreamWAV.LOOP_DISABLED=0  LOOP_FORWARD=1  LOOP_PINGPONG=2
```

写 `edit/loop_mode=1` 想表达"循环"，实际是"从 WAV 自动检测"；
脚本合成的 WAV 没有 `smpl` 块 → 判定为**不循环**，
表现为"BGM 放一遍就停"，**且不报任何错**。必须写 **`2`**。

**验证手法**：`scripts/_probe_wav.gd` 打印
`(load(path) as AudioStreamWAV).loop_mode`，前向循环时应等于 `AudioStreamWAV.LOOP_FORWARD`（1），
并且 `loop_end` 被引擎写成实际帧数（本项目 title 是 529199）而不是 0。

> 这两个默认值对每一批新素材都会复现，所以把它们固化成 `tools/patch_audio_import.py`，
> 而不是每次手改 `.import`。

## 三、AudioManager（autoload）

`scripts/core/audio_manager.gd`。**不要给它加 `class_name`**（会与 autoload 名冲突）；
场景脚本可以直接写 `AudioManager.xxx`，`--script` 测试里要走
`root.get_node_or_null("/root/AudioManager")`。

### 3.1 总线

运行时创建 `Master → Music / SFX`（不需要额外的 `default_bus_layout.tres`）。
`_ensure_buses()` 幂等，已存在就跳过。

各总线的线性音量写进 `AudioServer`：

| 接口 | 说明 |
|---|---|
| `set_master_volume(v)` / `get_master_volume()` | 0–1 线性 |
| `set_music_volume(v)` / `get_music_volume()` | 同上，默认 0.8 |
| `set_sfx_volume(v)` / `get_sfx_volume()` | 同上，默认 1.0 |
| `set_muted(bool)` | 静音 Master |
| `bus_volume(name)` | 读回实测值（静音时返回 0） |

写值即 `save_settings()` → `user://audio_settings.cfg`。
**与存档解耦**：没存档也该记得音量设置。

### 3.2 音效

* 定长 **14 个** `AudioStreamPlayer` 组成池，轮转取用（全忙就抢最久没播的那个）——
  避免同一帧多段音效互相打断，也避免频繁 new/queue_free。
* `play_sfx(id, pitch = 1.0, volume_db = 0.0) -> bool`
  * **未登记的 id** 直接返回 false 并 `push_warning`，**不写进 `play_failures`**
    （拼错 id 是调用方 bug，不该污染"素材缺失"诊断）
  * 素材缺失/加载失败才记 `play_failures`
* `played_log` 保留最近 64 条已播音效 id，供测试与调试断言（`played_count(id)`）。
* `pitch` 用来做同素材变奏：战斗里"拿起卡牌"用 `ui_click` + pitch 1.18 与按钮点击区分。

### 3.3 BGM

* **双播放器交叉淡入**：`play_bgm(id, fade)` 把新曲放到另一个 player 上从 -80dB 淡入，
  旧曲同步淡出后 `stop()`。
* **幂等**：同一首正在播则直接返回 true、**不重启** —— 开屏 → 主菜单 → 城镇 一路连贯。
* `stop_bgm(fade)` / `current_bgm()` / `is_bgm_playing()`。
* `ensure_loop()` 是**兜底**（素材重生成后忘了跑 patch 那两步时仍能循环）；
  正常路径由 `.import` 负责。帧数用 `get_length() × mix_rate` 反推，
  不读 `data.size()`（一旦将来换压缩格式就错）。

### 3.4 按钮点击音（自动挂接）

```gdscript
func _on_node_added(node: Node) -> void:
	if not button_sfx_enabled:
		return
	var b := node as BaseButton
	if b != null:
		wire_button(b)
```

在 `_ready()` 里接 `get_tree().node_added`。因为 autoload 的 `_ready` 早于主场景实例化，
**任何之后进入场景树的 `BaseButton` 都会被自动接上** —— 不需要在 5 个场景里各写一遍接线。
项目的 UI 大多是代码 `new()` 出来的，这条路是唯一省事的做法。

* `wire_button(b)` 幂等（用 meta `_audio_wired` 防重复连接），测试里也可直接调。
* `button_sfx_enabled` 是总开关。

## 四、接线位置

| 场景 | 做了什么 |
|---|---|
| `splash_scene` | `_ready` → `play_bgm("title")`；整屏点击时补一个 `ui_confirm`（"任意点击开始"不是按钮，不会被自动挂音） |
| `main_menu` | `_ready` → `play_bgm("title")`；新增**游戏设置**面板 |
| `town_scene` | `_ready` → `play_bgm("title")` |
| `run_scene` | `_ready` → `play_bgm("title")` |
| `battle_scene` | `_ready` → `play_bgm("battle")`；`_on_combat_feedback` → `_play_feedback_audio(p)`；结算 → `stop_bgm` + `victory`/`defeat` |

### 4.1 战斗事件 → 音效映射

映射表放在**场景层**（`battle_scene.FEEDBACK_SFX`），不是 AudioManager 里 ——
`AudioManager` 不需要知道战斗事件长什么样。分层与视觉特效一致：

```
battle_manager  只 emit combat_feedback（不知声音）
battle_scene    _play_feedback_audio(p) 解读
AudioManager    只管播
```

| 事件 | 条件 | 音效 |
|---|---|---|
| `attack_start` | `damage_type == "MAGICAL"` | `attack_magic`（咏唱） |
| `attack_start` | 其它 | `attack_phys`（破空） |
| `damage` | `damage_type == "MAGICAL"` | `hit_magic`（噼啪） |
| `damage` | 其它 | `hit_phys`（闷响） |
| `damage` | `crit == true` | **额外**再叠 `crit` |
| `shield` | — | `shield`（防御） |
| `heal` | — | `heal` |
| `mana` | — | `mana` |
| `combo` | — | `combo`（联合卡发动） |

为了让音效选得对，`battle_manager` 的表现层 payload 新增了 `damage_type` 字段
（字符串 `"PHYSICAL"` / `"MAGICAL"`，不塞枚举以免把数据类耦合进场景）。

另外：拖起手牌时 `ui_click`（pitch 1.18）；打出失败（资源不足/目标无效）时 `ui_deny`。

### 4.2 游戏设置面板

`main_menu.gd` 里代码搭建（`main_menu.tscn` 保持干净）：

* 三个滑杆（主音量 / 音乐 / 音效），取值与写值都走 `AudioManager` 的同名方法
  → 面板、总线、配置文件三者永远一致
* 静音勾选框
* 半透明遮罩拦背后点击；点遮罩或按 Esc 关闭
* 滑杆 / 百分比 Label 都设了 `name`（`Slider_音乐`、`Pct_音乐`…）供测试定位

## 五、验证方式

**听不到声音时，波形形状 + 能量包络 + 循环接缝就是可验证的替代品。**

### 5.1 素材探针 `tools/_probe_audio.py`

对每个 wav 输出：采样率 / 声道 / 时长 / 峰值 / RMS / 过零率（亮度代理）/ 循环接缝 `seam`，
并断言 6 条：
位深 16bit、峰值 0.2–0.999（排除静音与削波）、RMS ≥ 0.01、
BGM `seam ≤ 0.06` 且时长 ≥ 8s、音效时长 ≤ 2.5s、音效能量包络必须有动态
（最后一条只对音效生效 —— BGM 是持续音床，本来就该平稳）。
同时输出 `preview/_audio_probe.png`：每个文件一条波形 + 一条独立能量条。

## 六、已知限制与后续

* 音效是**合成音**，不是拟真录音。等真实音频素材到位后，替换 `assets/audio/*.wav`
  并保持文件名即可，代码零改动（`patch_audio_import.py` 只为 BGM 保留循环参数那步）。
* 目前只有 2 首 BGM 循环共用：城镇与地牢共用 `title`。后续如果做多场景，
  在 `BGM_FILES` 里加条目、在对应场景 `_ready` 里换 id 即可。
* 没有做"同类音效并发限流"（例：一次全体攻击 3 只怪会连播 3 次受击音）。
  如果听感变糊，可以在 `play_sfx` 里加"同 id 最小间隔"节流。
* 音量设置存在 `user://audio_settings.cfg`，**不在存档里** —— 换存档不会重置音量。
